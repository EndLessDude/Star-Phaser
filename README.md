# Star Phaser
### Game made by Shubham Dhall and Ronit Rana

## Description:
Star Phaser is a game where the user must clear 3 waves where they must collect all yellow and red stars without hitting any of the bombs.


## Controls:
- W - Click this to Jump
- A - Click this to move left
- D - Click this to move right

## Rules and Info:
- Collect the yellow stars and the big red star
- Yellow Star - 10 points each
- Red star - 100 points each
- Avoid the swift, flying bombs

## How to Win:
- Collect all the stars in each wave, at the end you should bat 660 points.
- Avoid getting hit by the bomb.

## Where we got the assets from:
We got the assets from Phaser: https://phaser.io/tutorials/making-your-first-phaser-3-game/part2
